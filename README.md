# data-science-exam

## Projektbeschreibung

Dieses Projekt umfasst die Bearbeitung der Prüfungsleistung im Modul Data Science an der DHBW Stuttgart. Gegeben war ein Datensatz bezüglich unterschiedlicher Städte ([cost-of-living.csv](./data/cost-of-living.csv)) und eine zugehörige Aufgabenstellung mit unterschiedlichen datenanalytischen Aspekten (Vorverarbeitung, Visualisierunv, Supervised/Unsupervised Learning, ...). 
Die Programmimplementierung befindet sich in [data_science_examp.ipynb](./data_science_examp.ipynb).
